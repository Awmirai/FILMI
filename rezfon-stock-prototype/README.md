# Rezfon Stock — Android Prototype

Separate offline-first inventory prototype for a mobile shop.

Prototype features:
- Quick sale (-1 stock)
- SQLite local persistence
- Glass / Case / Repair inventory
- Apple + Samsung demo catalogue
- Low-stock and out-of-stock detection
- Automatic suggested order quantity
- Shopping list with copy/share/CSV export
- Restock-to-target action
- Add custom article
- Stock transaction history
- Immediate low-stock notifications
- Weekly Monday shopping-list reminder

This is a prototype build for device testing. The next production phase should add multi-user/cloud sync, role permissions, branch/location stock, barcode scanning and demand-based reorder forecasting.
